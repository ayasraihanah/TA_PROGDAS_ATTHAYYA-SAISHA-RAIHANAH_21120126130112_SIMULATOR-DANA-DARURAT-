# TA_PROGDAS_ATTHAYYA-SAISHA-RAIHANAH_21120126130112_Simulator_Tabungan_dengan_Sistem_Penalti_(SaveQuest)-

#SaveQuest - Simulator Tabungan Gamifikasi

Tugas Akhir mata kuliah Teknologi Informasi. 
Aplikasi desktop (Python + tkinter) yang mengubah kebiasaan menabung menjadi game RPG bergaya pixel art.

# CONCEPT
-Elemen game:	Real-life adaptation
-HP Bar	Kesehatan dompet: saldo Dana Darurat dibanding targetnya
-HEAL	Menabung: HP naik dan dapat XP
-DAMAGE	Jajan impulsif: HP turun dan XP dipotong (penalti)
-Critical Hit / Heal	Transaksi besar (>= 10% target) memberi efek 2x
-Boss	Wishlist gadget: tabung untuk "menyerang" boss sampai kalah
-Level & XP	Makin rajin menabung, makin tinggi gelar (Rookie Saver sampai Legendary Tycoon)
-Game Over	Dana Darurat habis (HP = 0)

# FITUR PLANNING
-HP bar bersegmen + 5 hati, warna berubah (hijau / kuning / merah)
-Sistem XP, level, dan gelar karakter
-Wishlist gadget sebagai boss dengan HP bar yang menyusut saat ditabung
-Battle log riwayat transaksi berwarna
-Animasi: bintang berkedip, hero naik-turun, teks melayang, kilatan layar saat heal/damage
-Data tersimpan otomatis ke savedata.json
